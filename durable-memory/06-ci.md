# GitHub Actions

CI is enabled for pushes to main and workflow_dispatch. Five native jobs build,
run the full test.sh gate and upload binaries plus license/gnuplot patch assets:
Ubuntu 22.04 x64/arm64, macOS 15 ARM/Intel, Windows 2022 x64 with MinGW.
The compiler is @lmctl-ai/lmctl@0.2.460 installed in RUNNER_TEMP, never globally.
The current C++ SDK is verified by sdk.lock before building.

A green main push runs the release job only after the complete matrix succeeds.
That job alone has contents:write; build jobs have contents:read. It merges the
native artifacts, derives vX.Y.Z from the tested binary version, computes
SHA256SUMS and creates the release/tag at GITHUB_SHA. Previously published
versions are immutable and never overwritten by reruns or documentation pushes.
Bump CMakeLists.txt's project version for a changed release. Do not tag or
publish locally. Dispatch-only single-cell diagnostics never publish.

Concurrency is per source/run, so unrelated wiki-style pushes do not cancel
qualification of a published candidate. No platform cell is silently dropped.
The Windows python3 shim and native path conversion remain; macOS keeps only
system dylibs and Linux retains its dynamic glibc >=2.35 baseline checks.

Operation examples run through run_lmcode. Protocol tests capture private program files
from the real compiler and exercise the actual native host: strict manifests, retired selector refusal
(including native gnuplot), result ownership/framing, dry effects, first failure,
exits 0/2/3 (plus 4 for an unwritable frame where /dev/full exists) and rendering beyond the previous width cutoff. Six
pre-adoption parity cases preserve scalar/text values, exact PNG bytes and SVG
drawing bytes after normalizing only version metadata and native text newlines.

Cross-host lmcad/lmdraw combos run only when a compatible host is already on PATH
(it answers --lmcode-schema --json; CI never fetches one), and ffmpeg videos retain
their optional dependency check. A skip is reported explicitly and is not proof of those
external hosts' protocol adoption. The lmplot operation and standalone rendering
gates remain mandatory on the native matrix.
